# 📚 Algorithm Study & Implementation

A repository for understanding core algorithmic paradigms, advanced data structures, and implementing them directly in C.

---

## 📌 Curriculum & Roadmap

| No. | Topic | Core Concepts |
| :--- | :--- | :--- |
| 01 | **Sorting** | Insertion, Selection, Bubble, Merge, Quick, Heap Sort, Lower Bounds |
| 02 | **Tree Structures & Algorithms** | Binary Search Tree (BST), AVL Tree, Red-Black Tree, Trie |
| 03 | **Hashing** | Hash Functions, Collision Resolution (Chaining, Open Addressing), Hash Table |
| 04 | **Dynamic Programming** | Optimal Substructure, Overlapping Subproblems, Memoization, Tabulation |
| 05 | **Graph Algorithms** | DFS/BFS, Minimum Spanning Tree (Kruskal/Prim), Shortest Paths (Dijkstra/Bellman-Ford/Floyd-Warshall) |
| 06 | **String Matching** | KMP Algorithm, Rabin-Karp, Boyer-Moore |
| 07 | **NP-Completeness** | P vs NP, Polynomial-Time Reductions, Classic NP-Complete Problems |

---

## 🛠️ Environment

* **Language**: C (C99 / C11)
* **Compiler**: GCC / Clang / MSVC
* **Tools**: VS Code, GDB

---

## 📝 Naming Conventions

* **Source Code**: `[AlgorithmName].c` (e.g., `InsertionSort.c`, `Dijkstra.c`)
* **Notes & Documentation**: `README.md` or `Notes.md`
